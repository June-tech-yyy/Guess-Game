# 同频 · Same Frequency

每天一个题目，你说一个词，对面也在想同一个词——**你猜得到它想的那个吗？**

一次猜不中就罚你玩一个小游戏：按二十下、顺时针画两圈、憋笑五秒、把蓝点拖进圈里……十五种，随机抽，同一天同一个失误全世界抽到的是同一个。

> 为 Reddit「Game of the Day」黑客松做的每日小游戏，最终形态是装进 Reddit 的 Devvit 应用。
> 现在这一版是**纯前端可玩原型**（单文件、零依赖、手机浏览器直接打开）。

---

## 现在能玩到什么

- **12 个题材轮着出题**：水果、动物、职业、城市、电影、食物、运动、颜色、日用品、手机应用、交通工具、节日。每天一个题材，12 天一轮。
- **同一天，所有人同一题同一答案**——不是随机抽题，是按 UTC 日期算出来的，所以大家能对答案、能比连胜。
- **不是选择题**：自己打字，随便说。评分分七档，会告诉你差多远。

  | 判定 | 含义 | 分享格 |
  |---|---|---|
  | 同频 | 就是它 | 🟩 |
  | 很接近 | 两个标签重合（比如「苹果」vs「梨」都是水果、甜、圆） | 🟨 |
  | 沾边 | 一个标签重合 | 🟨 |
  | 同类，但不是它 | 你说的确实属于这一题（是城市），但不是它想的那个 | 🟦 |
  | 不像 / 不是这一类 | 完全不沾边，或者不在这一题里 | ⬛ |

- **说不认识的词不算次数**。词库外面的话（比如你突然说个「量子力学」），它会说「它没听懂」，这次不计次、不惩罚——想乱试也不会有代价。
- **最多四次机会**，猜错一次先跑一个惩罚，跑完才有下一次。
- **连胜**记录、结果可复制成表情格发出去。
- **练手模式**：今天的玩完了还能换别的题材接着玩（不计入连胜）。

## 十五种惩罚

按失误次数分三档，越往后越难，同一天同一次失误所有人抽到同一个（种子 = 日期 + 题目 + 第几次）。

| 档 | 惩罚 |
|---|---|
| 一 | 连点二十下 / 按住六秒不许松 / 石头剪刀布赢一次 / 十六格里找出不一样的那个 / 做个鬼脸（三秒后才许点「我做了」） |
| 二 | 滑块停在中间那条线上两秒半 / 把蓝点拖进虚线圈 / 左右交替划八次 / 记住三个词再从六个里挑出来 / 数红点 |
| 三 | 顺时针画满两圈 / 反着来（显示「左」必须点「右」）/ 按顺序点 1→4（位置打乱的）/ 抓住会跳的「真」按钮 / 憋笑五秒 |

## 跑起来

```bash
# 手机玩：电脑和手机连同一个 Wi-Fi
node serve.js 8080
# 然后手机浏览器打开终端打印出来的 http://<你的局域网IP>:8080

# 只在自己电脑上看：直接双击 index.html 也行
```

只想发给别人玩的话，把 `index.html` 拖到 [netlify.com/drop](https://app.netlify.com/drop)，几秒就有个公网地址。

## 自测

```bash
cd tools
node _check.js        # 12 题材 / 223 候选词 / 721 同类词 / 7 种判定 / 15 个惩罚全部确定性
node _widthcheck.js   # 惩罚小游戏的容器不能宽度塌陷（曾经真塌过，拖拽直接失灵）
node _sim.js          # DOM 桩里真点按钮：启动 → 练手 → 回今日
node _sim2.js         # 当天已玩过的存档也能安全进练手
```

## 目录

```
index.html              全部游戏代码（HTML + CSS + JS 单文件，约 55 KB）
serve.js                零依赖静态服务器，给手机调试用
extra-words.js          可选：构建期生成的外部词库（只扩「同类词」，不会成为答案）
tools/
  build-extra.js        从 sources/*.txt 或 --fetch 的 URL 列表生成 extra-words.js
  _check.js             数据与规则的不变量检查
  _widthcheck.js        惩罚容器宽度守卫
  _sim.js _sim2.js      DOM 桩交互模拟
sources/README.md       词库来源与格式说明
```

## 几个技术上的选择

- **不用 LLM**。判断「AI 想的是什么」靠的是预写词表加标签维度（比如水果的标签是 `甜/酸/温带/热带/圆形…`），重合几个标签就对应冷热几档。这样零延迟、零成本，而且**每天的结果是确定的**——换成真模型，同一句话两次问可能答案不同，就没法比连胜了。
- **答案是日期算出来的**，不是服务端存的。同一天全球同一个答案，断网也能玩，服务端只负责记录结果。
- **词库在构建期扩充**，不在运行时联网。评审在手机上点开，等一个接口超时就是体验报废；而且「最常见说法」这件事得人判断，不能交给接口。
- **惩罚和题目分开设计**：惩罚是为了「失误也不烦」，所以设计成 3–20 秒能过、有画面、可截图，而不是惩罚得让人想关掉页面。
